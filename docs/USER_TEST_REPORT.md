# 사용자 테스트 기록 — AI Commerce P0

**상태: 미실시 (준비 완료).** 외부 배포 후 실제 사용자 5명 이상으로 진행한다.
Seed Persona·자동 브라우저·개발자 본인은 사용자 수에 포함하지 않는다.

## 목적

P0 세 과제가 개발자가 아닌 실제 사용자에게도 끝까지 동작하는지 확인하고, 막힌 지점과 피드백을 수집해 서비스에 반영한다.

## 참여자에게 부여하는 과제

| 과제 | 사용자에게 전달하는 지시 |
| --- | --- |
| T1 쇼핑 | "배송비 포함 20만원 안에서 개발용 모니터를 비교해서, 마음에 드는 옵션을 장바구니에 담아 주세요." |
| T2 주문/배송 | "본인 주문 중 배송 중인 건 지금 어디까지 왔는지 AI에게 물어보세요." |
| T3 취소 | "아직 배송 안 간 주문을 AI에게 취소해 달라고 하고, 화면 안내를 따라 진행해 보세요." |

## 진행 방법

1. 배포 URL과 **개인별 접근 코드를 비공개 채널로 각각 전달**한다. 코드 목록 전체는 공개하지 않는다.
2. 참여자에게 지시 문구만 전달하고, 화면을 관찰하거나 녹화한다. 막히면 개입하지 말고 기록한다.
3. 세션 후 아래 항목을 기록한다.

## 관찰 포인트

- T1: 추천 이유와 근거 리뷰를 이해했는가? 옵션 선택/수량 지정에서 막혔는가? AI가 카트를 바꾼 결과를 신뢰했는가?
- T2: AI가 올바른 주문을 골랐는가? 배송 상태 설명이 이해 가능했는가? 정보가 없는 주문에서 "없다"고 말했는가?
- T3: AI가 바로 취소하지 않고 확인을 요구한 것을 이해했는가? "취소 요청 접수"와 "취소 완료/환불 완료"를 구분해 이해했는가?
