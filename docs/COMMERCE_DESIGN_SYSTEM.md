# Commerce 디자인 시스템 추출 — 토스쇼핑 레퍼런스 기반 (2026-10-07)

목적: 토스쇼핑 캡처(130장)와 공개 Toss Design System(TDS) 문서에서 구매자 UI 구현에 필요한 디자인 규칙을 추출한다. 토스 브랜드 자산(로고·폰트·아이콘·문구)의 복제가 목적이 아니라, **유사한 UX 구조를 가진 테스트 커머스 환경**을 만들기 위한 참고 기준이다.

## 0. 표기 원칙

- `[Observed]` = `reference/toss-shopping/screenshots/` 실측값(픽셀 색상 추출 + 화면 열람). 스크린샷 해상도 880×1920px이며 약 2x 스케일로 보고 pt 환산했다.
- `[TDS]` = 공개 문서(tossmini-docs.toss.im/tds-mobile, tds-react-native)의 공식 토큰. **토스쇼핑 앱의 확정값이 아니라 공통 규칙으로만 사용한다.**
- `[Inferred]` = 캡처에서 확인되나 정확한 수치 측정이 불가한 추정값.

공개 TDS에는 라이트 테마 토큰만 있고 다크 테마 토큰표는 비공개라, 다크 앱의 실제 색상은 전부 `[Observed]` 실측값을 우선한다.

## 1. Typography

### 폰트 전략

| 항목 | 내용 |
| --- | --- |
| 토스 앱 본문 폰트 | 캡처만으로 서체 확정 불가 [Inferred]. 참고로 공개된 'TossFace'는 **이모지 전용 폰트**이며 본문 산세리프가 아니다. 토스쇼핑 본문에 쓰이는 서체는 비공개/미확인으로 보고, 캡처상 중성적인 한글 산세리프 특징(균일한 획 대비·좁은 자폭 경향)만 구조적으로 참고한다 |
| 권장 대체 | **Pretendard** (SIL Open Font License 1.1, 한글 산세리프, 토스 UI와 계열이 유사해 실무에서 토스류 UI의 표준 대체재로 널리 사용) |
| Fallback | `-apple-system, Pretendard, 'Malgun Gothic', 'Apple SD Gothic Neo', sans-serif` |
| 현재 구현 | 시스템 스택만 사용(`-apple-system/Segoe UI/Malgun Gothic`) — Pretendard 미도입 |

### 크기 단계 (캡처 관측 추정, pt)

| 용도 | 추정 크기/굵기 | 근거 |
| --- | --- | --- |
| 대형 가격(상세) | 20~22pt, Heavy/Bold | 상세 '20,800원' 영역이 이름의 ~1.5배 [Observed 비율, Inferred 수치] |
| 화면 타이틀/질문 | 19~20pt, Bold | '취소하는 이유는 무엇인가요?', '어떤 수단으로 결제할까요?' [Observed] |
| 섹션 헤더 | 15~17pt, Bold | '전체 리뷰', '배송지', '결제 정보' [Observed] |
| 상품명/본문 | 14~15pt, Medium | 카드·리스트 본문 [Inferred] |
| 보조/메타 | 12~13pt, Regular | '100g당 N원', '최대 N원 적립', 리뷰 메타 [Inferred] |
| CTA 라벨 | 17~18pt, Bold | '구매하기', 'n원 결제하기' [Observed] |
| 배지/칩 | 11~12pt, Bold | 'n% 특가', '역대급 특가' [Inferred] |

참고 — TDS 공식 타이포 `[TDS]`(pt): T3 22/31, T4 20/29, T5 17/25.5, T6 15/22.5, T7 13/19.5, st8 19/28. 라이트 테마 기준이며 쇼핑 앱 측정값과 반드시 일치하지 않으므로 매핑 참고로만 쓴다.

| 별점 | 오렌지~골드 계열 (정확치 미측정) | ★ 표기 — 캡처상 웜 옐로 [Inferred] |

| 취소선/비활성 | 회색 스트라이크 + 낮은 불투명 | '40% ~~35,000원~~' |
| 라이트 카드(프로모/이미지 배경) | `#F7F0EB` 등 밝은 톤 | 홈 히어로 카드, 상품 사진 배경 — 다크 UI 안에서 이미지 카드만 밝게 처리 |

TDS 공식 라이트 토큰 `[TDS]`(참고): `blue500 #3182F6`, `red500 #F04452`, `grey900 #191F28`, `grey500 #8B95A1`, `grey600 #6B7684`. 실측 블루 `#2975F4`·레드 `#ED2C3B`가 TDS와 근사하므로, **프로젝트 토큰은 실측값을 표준으로 하고 TDS를 fallback 근거로 둔다.** 현재 `styles.css`의 `--bg #17171c`·`--accent #3182f6`은 방향이 맞지만 카드·칩·레드 계열 정밀 조정이 필요하다.

## 4. 컴포넌트 스펙

### 상품 카드 (리스트/그리드) `[Observed]`

- 2열 그리드, 이미지 정사각(1:1) 상단, 좌상단 `n% 특가` 빨간 pill 배지, 이미지 우하단 장바구니 아이콘 버튼(둥근 흰/반투명 배경).
- 텍스트 블록: 상품명 최대 2줄 → `n%`(빨간 bold)+가격(bold) → `100g당 N원` 단가(보조) → `★평점(개수)` → `최대 N원 적립`(보조).
- 홈에는 '역대급 특가' 대형 가로 카드(이미지 좌+정보 우)가 별도 존재.

### 상품 이미지 규격 `[Observed]`

- 리스트 카드: 1:1 정사각.
- 상세 상단: 화면폭 대형(1:1~4:3) + 우하단 `n|m` 페이지 인디케이터 pill + 좌하단 '비슷한 상품' pill(썸네일 2개+텍스트).
- 갤러리 뷰어: 전체 화면 전환(별도 캡처 071/072 존재).
- 품절: 이미지 위 딤드 + 중앙 '품절' + 보조 문구('밤 12시부터 구매할 수 있어요'), CTA '품절' 비활성.

### 검색·카테고리 `[Observed]`

- 검색 필드: 둥근 입력(돋보기+placeholder+우측 X 지우기), 포커스 시 자동완성 리스트(입력 부분만 파란 강조).
- 최근 검색어: 시계 아이콘+단어+우측 X 삭제 행.
- 검색 결과 상단: 패싯 행(중량/국내산 등 가로 스크롤), 칩 행('필터' 버튼+'추천순 ⌄'+OASIS/최저가보장/베스트판매 토글 칩).
- 필터: **전체 페이지**(시트 아님) — 상단 탭(가격대/카테고리/브랜드/특징, 언더라인 선택)+칩 그룹+'더 보기 ⌄'+하단 '402개 상품 보기' 카운트 CTA.
- 정렬: 바텀시트(선택 항목 파란 ✓+설명 문구).

### Header / Bottom Navigation `[Observed]`

- 홈 헤더: 검색 필드 + 마이(사람 아이콘) + 장바구니(빨간 배지 숫자) 아이콘.
- 상세 헤더: 이미지 위 투명 오버레이 아이콘(좌: 뒤로가기, 우: 공유/검색/장바구니). 스크롤 시 변화는 별도 캡처로 미정밀 확인(상단 영역만 관찰됨) `[Inferred]`.
- 하단 네비: 5탭 아이콘+라벨(홈/혜택/쇼핑/습관/전체), 선택 탭은 밝은 아이콘+라벨, 높이 약 56pt, 배경과 동일 톤+상단 구분선. **현재 앱에는 없음 — 구매자 UI에는 필요한 골격.**

### Bottom Sheet `[Observed]`

- 딤드 오버레이 + 상단 라운드(~20pt) + 상단 타이틀.
- 옵션 시트: '옵션 한번에 보기' 타이틀 + 옵션 카드 리스트(가격 표시) + 선택 시 파란 강조.
- 정렬 시트: 항목+설명 문구+선택 ✓.
- 현재 앱의 취소 시트와 구조는 동일 — 컴포넌트 재사용 권장.

### CTA 버튼 `[Observed]`

- Primary: 전체 폭, `#2975F4`, 흰 텍스트, 높이 ~52~56pt, radius ~12~14pt. 금액을 라벨에 포함('18,142원 결제하기', '5건 · 81,940원 주문하기').
- 보조: 다크 필 버튼(카드색과 유사한 `#24262E` 계열) '가격 비교하기', '취소하기/문의하기' 행 버튼.
- 비활성: 회색 필+회색 텍스트('품절', '다음' 미선택).

### 리뷰·가격·할인 표현 `[Observed]`

- 가격 블록: `n%`(레드 bold) + 원가 취소선(회색) → 판매가 대형 bold + '최대할인가 ⌄'(레드 소형+펼침) + '가격 비교하기' 칩(우측).
- 단가: '100g당 N원' 보조 텍스트.
- 리뷰 요약 행: '평점·리뷰 | ★4.8 (1,123)' + chevron.
- 리뷰 목록: 요약(별점+평균+개수+사진 스트립+더보기) → 카드(★ + 마스킹 작성자 '김*정' + 날짜 + ⋯ 메뉴 + '옵션/판매자' 메타 + 사진 + 본문 + 'N명에게 도움 됐어요 👍').

### 주문·배송 공통 `[Observed]`

- 주문 목록 카드: 상태 헤더('결제완료 n월 n일 도착 예정' / '취소완료' / '구매확정'+'배송 조회' 칩) + 날짜 링크('n.n (요일) 결제 상세 >') + 썸네일+상품+가격·수량 + 행 버튼(취소하기/문의하기/리뷰 쓰고 받기).
- 주문 상세: '주문 상세 내역'+'영수증 보기' 칩, 상태 카드, 배송지 블록(이름/주소/폰/'배송메모 | #xxxx#' + 변경 안내 점선 박스), 결제 정보 테이블(라벨 좌/금액 우, 할인·환불은 블루).
- 배송 조회: 목록 카드 '배송 조회' 칩 — 별도 조회 화면은 미촬영(shipping/093은 상품 페이지 배송 안내 시트). 현재 앱의 주문 상세 타임라인은 기능적으로 동등.
- 주문 취소: **단계형 전체 페이지** — ①사유 선택(라디오형 행+상세 입력 textarea) → ②'환불 예정 금액을 확인해주세요'(금액 분해+총액 블루 강조+취소 안내 불릿) → ③'취소 요청' 실행 → ④완료 화면(타이틀+판매자 카드+취소 사유 표시+확인).
- 결제 완료: 센터 체크 아이콘+타이틀+적립 CTA+주문 카드+배송지+안내 박스+Primary('홈으로 가기')+보조 링크('주문 상세 내역 보기').
- CS: '문의 내용을 선택해주세요' 슬라이드 패널(주제 행 >) → 채팅 UI(버블+입력 바+스켈레톤).
