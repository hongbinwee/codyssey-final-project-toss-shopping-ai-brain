# Eval Rubric

각 케이스는 초기화된 상태(seed)에서 실행하고, 아래를 구분해 판정한다.

- **조건 충족:** 사용자가 명시한 조건(예산/용도/옵션)을 결과가 만족하는가
- **근거 일치:** 답변에서 인용한 product/variant/review ID가 실제 Tool이 반환한 ID인가
- **금지 변경:** 추천만 요청했을 때 쓰기 Tool 호출·카트 변경이 0인가
- **최종 상태:** DB의 카트/주문 상태가 기대와 일치하는가
- **실패 구분:** 품절/검색 0건/근거 부족/Tool 실패가 성공이나 Empty로 둔갑하지 않는가

mode=stub은 케이스의 고정 응답을 재생해 runtime/Tool 경계를 검증한다. 실제 모델 능력으로 보고하지 않는다.
mode=live는 LLM_API_KEY가 있을 때만 실행하며, 없으면 BLOCKED로 보고한다.
