> **시점 주의:** 이 감사는 UI-1(2026-10-07 홈·검색·목록 1차 구현) **이전** 상태의 스냅샷이다. 이후 변경(하단 네비·아이콘 시스템·카테고리 pill·상품 이미지 convention·개발 서버 3200 포트)과 현재 프로젝트 방향은 §11과 `docs/IMPLEMENTATION_PROGRESS.md`, `PROJECT_CONTEXT.md` §현재 프로젝트 방향을 함께 읽는다.

## 3. 구매 Flow 동작 여부

직접 확인(이번 감사 브라우저)과 기존 테스트 확인을 구분한다.

**직접 확인한 것**: 로그인 → 상품 그리드 → 상품 상세 → 옵션 선택(품절 옵션 비활성 확인: v-a-27 '품절' 배지+disabled) → 수량 표시 → 장바구니 담기 피드백+헤더 배지 '1' → 카트 화면 → 주문서 견적 화면 → 주문 목록(시드 3건 상태 배지) → 주문 상세(PREPARING/IN_TRANSIT 타임라인) → 취소 시트 열림(로딩 상태) → AI 패널 shopping 답변(비교 카드+근거 칩) → CS 답변(배송 상태 설명, `(로컬 stub)` 표기).

**기존 테스트로만 확인한 것**(`docs/VERIFICATION_LOG.md` 기준, 이번 감사에서 미실행):

- 결제 confirm → 주문 생성 → 주문 상세 이동, 재고 차감, 견적 만료·경합 거절(e2e checkout-t2 등)
- 카트 수량 변경·삭제·버전 경합·멱등 재생(integration+e2e)
- 취소 자격/견적/승인/실행 전체, REQUESTED→처리(주문·배송 CANCELLED+재고 복원+환불 PENDING→REFUNDED) 시뮬레이터 전환
- 최신 verify --phase=5 결과: unit 18/18, integration 58/58, e2e 14/14, dev eval 16/16, holdout 18/18(6케이스×3)

## 5. 상품 이미지 누락

- `products.image_urls`가 **3개 상품 모두 빈 배열**이다. UI는 `name.slice(0,1)` 첫 글자를 그라데이션 배경 위에 표시하는 플레이스홀더로 대체한다.
- 영향 범위: 상품 카드 썸네일, 상세 히어로, 카트/주문서/주문 상세 썸네일 전부 글자 플레이스홀더.
- 토스쇼핑은 리스트 카드 정사각 실사진 + 상세 갤러리(페이지 인디케이터 n|m, '비슷한 상품' pill)라 시각 밀도 차이가 가장 크다. UI 개선 시 우선순위 최상위.
